# Courses Management System

Це навчальний Java-проєкт для керування студентами, курсами, завданнями та модулями навчання.
Проєкт демонструє принципи об’єктно-орієнтованого програмування (OOP) та використання фабричних методів.

---

# Структура проєкту

CoursesClass/
|-- Main.java # Головний клас для запуску програми
|-- Student.java # Клас студента
|-- Assignment.java # Клас завдання
|-- Module.java # Клас модуля курсу
|-- Utils.java # Утилітні методи для валідації
|-- ValidationHelper.java # Своєрідні Exception's
----------------------------------------------------

- Принципи OOP: класи, приватні поля, методи, фабричні методи
- Валідація даних через утилітний клас `Utils`

-----------------------------------------------------

#Функціонал

 Створення студента (Student)

 Створення завдання (Assignment)

 Створення модуля курсу (Module)

 Створення курсу (Course)

 Створення викладача(інструктора) (Instructor)

 --Валідація даних--
 Клас Utils перевіряє коректність введених даних для студентів та модулів:

----------Примітки----------
    Конфлікт імен класу Module з java.lang.Module усунуто через вказання повного шляху CoursesClass.Module.

    Всі фабричні методи (createStudent, createAssignment, createModule) є статичними.

    Конструктори класів Student, Assignment, Module, Course, Instructor private, щоб використовувати лише фабричні методи.

    Валідація даних гарантує коректність email, дат та назв курсів/модулів.
